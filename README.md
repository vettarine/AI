### 1. Теоретическая база

В основе данной работы лежит задача классификации изображений с использованием методов глубокого обучения и трансферного обучения. Сверточные нейронные сети (CNN) демонстрируют высокую эффективность в задачах компьютерного зрения благодаря способности автоматически извлекать признаки различной сложности и формировать устойчивые представления объектов на изображениях.

В качестве основной архитектуры использована InceptionV2 (реализация Inception-ResNet-V2). Архитектура объединяет идеи Inception-модулей и остаточных связей (ResNet), что позволяет повысить стабильность обучения и ускорить сходимость модели. Параллельные свертки разных размеров обеспечивают извлечение признаков различных масштабов.

В работе были реализованы два режима обучения:

- Дообучение (fine-tuning) — использование модели с предобученными весами ImageNet с заменой последнего слоя для классификации 120 пород собак.

- Обучение с нуля (from scratch) — инициализация модели случайными весами и полное обучение на целевом датасете.

В ходе экспериментов использовались следующие оптимизаторы:

- Adam — адаптивный метод оптимизации, основанный на оценке первого и второго моментов градиента.

- AdaSmooth — оптимизатор, использующий сглаживание градиентов для стабилизации процесса обучения и уменьшения колебаний весов.

В качестве набора данных использован Stanford Dogs Dataset, содержащий изображения 120 пород собак.

### 2. Описание разработанной системы

Принцип работы системы:

- Датасет Stanford Dogs размещается в директории проекта и загружается средствами PyTorch.

- Выполняется предобработка изображений: масштабирование до 224×224 пикселей, случайные отражения и повороты, нормализация.

- Данные разделяются на обучающую, валидационную и тестовую выборки в пропорции 70/15/15.

- Создается модель InceptionV2 в одном из трех режимов:

      Эксперимент 1: дообучение с оптимизатором Adam.

      Эксперимент 2: дообучение с оптимизатором AdaSmooth.

      Эксперимент 3: обучение с нуля с Adam.

- Модель обучается в течение нескольких эпох с вычислением функции потерь и обновлением весов.

- После завершения обучения проводится оценка модели на тестовой выборке.

- Рассчитываются метрики Precision и Recall для сравнения эффективности моделей.

Архитектура системы:

- Входные данные: изображения формата JPEG.

- Предобработка: Resize(224×224), RandomHorizontalFlip, RandomRotation, преобразование в тензоры.

- Модель: Inception-ResNet-V2.

- Функция потерь: CrossEntropyLoss.

- Оптимизаторы: Adam, AdaSmooth.

- Фреймворк: PyTorch.

- Метрики оценки: Precision (macro), Recall (macro).

Алгоритмические этапы:

- Загрузка изображений через torchvision.datasets.ImageFolder.

- Разделение датасета на обучающую, валидационную и тестовую части.

- Замена выходного слоя модели на слой с количеством нейронов, равным числу классов.

- Реализация цикла обучения с обратным распространением ошибки.

- Вычисление метрик качества на тестовой выборке с использованием sklearn.metrics.

- Сравнение результатов различных экспериментов.

### 4. Выводы по работе

Дообучение предобученной модели позволило значительно повысить качество классификации по сравнению с обучением с нуля.

Оптимизатор Adam показал наилучшие результаты по метрикам Precision и Recall.

AdaSmooth продемонстрировал стабильную сходимость и сопоставимые результаты при тонкой настройке модели.

Архитектура InceptionV2 оказалась эффективной для задачи классификации изображений большого количества классов.

Разработанная система имеет модульную структуру и может быть расширена для проведения дополнительных экспериментов и использования других архитектур нейронных сетей.
