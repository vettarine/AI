1. Теоретическая часть

Данная лабораторная работа посвящена разработке системы автоматической классификации новостных текстов на реальные и фейковые с использованием методов машинного обучения. Задача обнаружения недостоверной информации относится к актуальным проблемам обработки естественного языка и анализа текстовых данных, особенно важна в современном информационном пространстве, где распространение фейковых новостей может иметь серьезные социальные и политические последствия.

В основе системы лежит классический подход машинного обучения для текстов, состоящий из двух основных этапов. Первый этап - векторизация текстов с использованием метода TF-IDF, который преобразует неструктурированные текстовые данные в числовые векторы. TF-IDF учитывает как частоту термина в конкретном документе, так и его редкость во всем корпусе документов, что позволяет выделить наиболее значимые слова для каждого текста. Этот метод эффективно преобразует тексты в формат, пригодный для алгоритмов машинного обучения.

Второй этап - классификация с использованием двух алгоритмов машинного обучения. Logistic Regression представляет собой линейную модель, оптимальную для бинарной классификации, которая моделирует вероятность принадлежности текста к классу фейковых новостей. Support Vector Machine - это метод опорных векторов, который находит оптимальную разделяющую гиперплоскость в пространстве признаков, максимизируя зазор между классами. Оба алгоритма хорошо зарекомендовали себя в задачах текстовой классификации.

Для оценки качества моделей используются стандартные метрики классификации. Accuracy показывает общую точность классификации, Precision измеряет точность предсказания положительного класса, Recall оценивает полноту обнаружения фейковых новостей. F1-Score представляет собой гармоническое среднее между Precision и Recall, что особенно важно при несбалансированных классах. ROC-AUC показывает качество разделения классов моделью, где значение близкое к 1.0 указывает на отличную разделяющую способность.

Важной частью работы является предобработка текстовых данных, которая включает очистку текста от HTML-тегов, URL-адресов, специальных символов, токенизацию, удаление стоп-слов и лемматизацию. Эти этапы необходимы для улучшения качества векторизации и последующей классификации. Балансировка классов также играет важную роль, поскольку дисбаланс в данных может привести к смещенным предсказаниям модели.

2.  Описание разработынной системы

Разработанная система представляет собой комплексное решение для классификации новостей на реальные и фейковые, реализующее полный цикл обработки данных от загрузки до оценки результатов. Система имеет модульную архитектуру, что обеспечивает гибкость и возможность легкой модификации отдельных компонентов.

Основной скрипт системы координирует выполнение всех этапов работы. Начинается процесс с инициализации конфигурационных параметров и создания необходимых директорий для сохранения результатов. Затем происходит загрузка текстовых данных из структурированных папок, где каждая новость хранится в отдельном текстовом файле, а метка класса определяется по названию папки. Система автоматически обрабатывает как тренировочные, так и тестовые данные.

Предобработка данных включает несколько важных этапов. Тексты очищаются от HTML-разметки, URL-адресов и специальных символов, приводятся к нижнему регистру для единообразия. Затем выполняется токенизация - разделение текстов на отдельные слова с использованием библиотеки NLTK. Удаляются стоп-слова - часто встречающиеся слова, которые не несут значимой информации для классификации. Применяется лемматизация - приведение слов к их нормальной форме, что позволяет сократить размерность признакового пространства.

Особое внимание уделено проблеме дубликатов данных. В процессе тестирования была обнаружена критическая проблема - все тестовые данные полностью дублировали тренировочные, что приводило к некорректной оценке моделей. Для решения этой проблемы была реализована проверка на дубликаты через вычисление хэш-сумм текстов и автоматическое создание нового корректного разделения данных на тренировочную и тестовую выборки.

Векторизация текстов выполняется с использованием метода TF-IDF с параметрами, оптимизированными для данной задачи. Создается 5000 признаков, включая как отдельные слова, так и биграммы для захвата контекста. Векторизатор обучается только на тренировочных данных, после чего применяется к тестовым данным для обеспечения корректной оценки.

Обучение моделей осуществляется с использованием техники GridSearch для автоматического подбора оптимальных гиперпараметров. Для каждой модели тестируются различные комбинации параметров, выбираются наилучшие на основе кросс-валидации. Это позволяет получить модели с максимальной производительностью без ручного подбора параметров.

Система включает комплексную оценку качества, включая расчет всех основных метрик классификации, построение матриц ошибок, ROC-кривых и кривых Precision-Recall. Также выполняется анализ важности признаков, что позволяет понять, какие слова наиболее значимы для классификации и интерпретировать решения моделей.

Визуализация результатов занимает важное место в системе. Автоматически генерируются графики, показывающие производительность моделей, распределение ошибок, важность признаков.

3. Результаты работы и тестирования системы

Результаты работы системы демонстрируют высокую эффективность в задаче классификации фейковых новостей. После корректного разделения данных и устранения проблемы дубликатов были получены реалистичные и воспроизводимые результаты, отражающие истинную производительность моделей.

Logistic Regression показала лучшие результаты среди двух тестируемых моделей. На тестовой выборке модель достигла accuracy 86.57%, что означает правильную классификацию 86.57% новостей. F1-Score составил 86.56%, демонстрируя хороший баланс между точностью и полнотой. Precision модели равен 86.63%, что означает высокую точность определения фейковых новостей. Recall составил 86.57%, показывая, что модель находит большинство фейковых новостей. ROC-AUC достиг значения 88.74%, что указывает на хорошую способность модели разделять классы.

Support Vector Machine также показала хорошие результаты, хотя несколько уступила Logistic Regression. Accuracy SVM составила 85.28%, F1-Score - 85.27%, Precision - 85.28%, Recall - 85.28%. При этом ROC-AUC SVM оказался немного выше - 90.19%, что говорит о несколько лучшей разделяющей способности этой модели, хотя общие метрики классификации оказались ниже.

Анализ матриц ошибок выявил характерные паттерны ошибок обеих моделей. Logistic Regression правильно классифицировала 274 реальные новости и 261 фейковую, допустив 35 ложноположительных ошибок и 48 ложноотрицательных. SVM показала схожую структуру ошибок: 266 правильных классификаций реальных новостей, 261 фейковая новость определена верно, 43 ложноположительных и 48 ложноотрицательных ошибок. Обе модели демонстрируют сходную чувствительность к фейковым новостям, но несколько различаются в определении реальных новостей.

Проверка на переобучение выявила умеренное переобучение моделей, что является типичным для текстовых данных с большим количеством признаков. На тренировочных данных Logistic Regression достигла accuracy 99.86%, а SVM показала идеальные 100%. На тестовых данных результаты составили 86.57% и 85.28% соответственно. Кросс-валидация подтвердила стабильность моделей: средний F1-Score Logistic Regression составил 77.73% с небольшим стандартным отклонением, SVM показала 75.38%.

Анализ важных признаков выявил следующие закономерности в данных. Для Logistic Regression наиболее значимыми словами оказались "insider" с важностью 39.12, "wednesday" - 26.81, "stated" - 24.62, "tuesday" - 24.38, "caused" - 23.40. Для SVM важными признаками были "stated" - 3.96, "liberal" - 3.70, "tuesday" - 3.55, "fourth" - 3.44, "insider" - 3.20. Эти результаты показывают, что реальные новости чаще содержат официальные формулировки, временные маркеры, профессиональную терминологию.

Система успешно справилась с обнаруженной проблемой data leakage. Изначальные тестовые данные полностью дублировали тренировочные, что приводило к искусственно завышенным метрикам. После реализации проверки на дубликаты и создания нового корректного разделения данных были получены реалистичные оценки производительности моделей.

Все результаты работы системы сохранены в удобном для анализа формате. Созданы графики ROC-кривых, матриц ошибок, важности признаков. Сгенерированы подробные текстовые отчеты с анализом результатов. Модели и векторизатор сохранены для возможного повторного использования. Система показала себя как надежный инструмент для исследования и практического применения в задаче классификации новостей.

4. Выводы по работе

Проведенная работа подтвердила эффективность традиционных методов машинного обучения в сочетании с TF-IDF векторизацией для задачи классификации фейковых новостей. Обе тестируемые модели показали высокие результаты с accuracy выше 85%, что свидетельствует о возможности успешного решения задачи с использованием относительно простых и интерпретируемых методов.

Сравнение двух алгоритмов показало, что Logistic Regression незначительно превосходит SVM по основным метрикам классификации, достигая F1-Score 86.56% против 85.27% у SVM. При этом Logistic Regression обладает преимуществами в скорости обучения и интерпретируемости результатов, что делает ее предпочтительным выбором для подобных задач. SVM, хотя и показала несколько более высокий ROC-AUC, требует больше вычислительных ресурсов и сложнее в интерпретации.

Критически важным аспектом работы оказалась проверка данных на корректность разделения. Обнаруженная проблема полного дублирования тестовых и тренировочных данных подчеркивает необходимость тщательной проверки датасетов перед обучением моделей. Реализованный механизм проверки и устранения дубликатов позволил получить достоверные оценки производительности моделей и избежать искусственно завышенных результатов.

Анализ важных признаков предоставил ценную информацию о различиях между фейковыми и реальными новостями. Выявлено, что реальные новости характеризуются использованием официальной лексики, временных маркеров, профессиональной терминологии. Эти инсайты могут быть использованы не только для улучшения моделей, но и для образовательных целей в области медиаграмотности.

Система демонстрирует умеренное переобучение, что является ожидаемым для текстовых данных с большим количеством признаков относительно объема выборки. Использование регуляризации и кросс-валидации позволило контролировать этот эффект и получить модели с хорошей обобщающей способностью.

Разработанная система обладает практической ценностью и может быть использована в различных приложениях. Она может служить инструментом автоматической модерации контента, образовательной платформой для обучения распознаванию фейковых новостей, компонентом более сложных систем анализа информационных потоков. Модульная архитектура системы позволяет легко адаптировать ее для решения схожих задач текстовой классификации.
